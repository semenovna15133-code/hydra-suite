## 18. ГЛОССАРИЙ
═══════════════════════════════════════════════════════════════
Без изменений + новые термины:
hb_stats.json — файл статистики hydra-bridge (rx/tx/dup/retrans).
Orphan sweep — убийство процессов-сирот бэкендов перед стартом туннеля.
Roam-aware — реконнект только после 6-сек подтверждения стаза rx.
Single-flight — один автоконнект за раз (mutex-воронка).
Evidence — доказательство живости кандидата до объявления «connected».
Supervised retries — надзорные ретраи 15/30/60/120с при провале всех.
