Hydra Client 0.3.1 — импорт ключей по QR

Новое:
- Панель генерирует QR с Key File v2: кнопка «QR» на странице клиента
  (роут /keys/{id}/qr.png, идентичен .conf по содержимому — проверено end-to-end).
- Клиент: встроенный QR-сканер — камера И декодирование из галереи (скриншоты).
- Импорт через системные интенты: файловый менеджер (.key/.conf),
  шаринг text/plain, диплинк hydra://import/<base64>, content:// URI.
- Автоимпорт pending-ключа при старте приложения.
- Убраны заглушки: реальный парсинг keyfile из текста/файла/ссылки.

Исправлено:
- Дедупликация intent-фильтров в AndroidManifest, методов SettingsStore/settings.dart.
- handleIncomingIntent: content:// через contentResolver, file:// с fallback
  (Scoped Storage Android 10+).

Установка:
1. Скачай hydra-client-0.3.1-arm64.apk (реальные устройства) или -x86_64 (эмулятор).
2. Разреши установку из неизвестных источников.
3. Открой панель -> клиент -> «QR»; в приложении «Сканировать QR» -> камера/галерея.
   Либо «Импортировать ключ» -> выбрать .conf файл.
4. «Подключиться» на карточке ключа.

Требования: Android 8.0+ (API 26); 32-бит ARM (armeabi-v7a) не поддерживается
(как и в 0.3.0).
