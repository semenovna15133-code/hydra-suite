Hydra Client 0.3.41 — фикс багажа статистики при failover

Проблема: при failover WDTT → AWG (или любом переключении протокола)
sessionBaseRx/Tx не сбрасывались, и новый протокол видел багаж байтов
из прошлой сессии (например, 55 МБ за 3 секунды в AWG-сессии).

Исправлено: snapshotStatsBase() вызывается при каждом старте туннеля
в startMultiprotocolTunnel, а не только при нулевой базе. Теперь
статистика каждого протокола честная: rx_bytes/tx_bytes = реальный
трафик текущей сессии.
