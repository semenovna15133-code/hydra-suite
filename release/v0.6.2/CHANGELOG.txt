Hydra Client 0.6.2 — UI по спецификации (фикс потерянных правок 0.6.1)

1. Три головы сверху (AWG · WDTT · AIVPN), AUTO-головы НЕТ:
   тап по голове = явное подключение ТОЛЬКО через этот протокол,
   без SmartConnect и без failover на другие протоколы.

2. Ошибка явного режима: "<PROTO> недоступен. Попробуйте режим AUTO"
   (watchdog 6-20с по статусу туннеля).

3. Большая центральная кнопка = AUTO (SmartConnect: probe → score → failover).

4. Заголовок: "Hydra VPN" (вместо "Neon Hydra").

5. Статус-строка: "Режим: X · работает Y · сервер <label>"
   (имя сервера из _serverInfo вместо latency).

6. AWG в явном режиме: ожидаемое поведение — "AWG недоступен"
   (Go-биндинг временно отключён из-за gomobile-конфликтов).
