Hydra Client 0.8.0 — Расширенное логирование для тестирования всех трёх протоколов

Новые возможности:
- Увеличенное окно logcat (50000 строк вместо 3000) — можно собрать длинные сессии
- Method channel clearLogcat — для начала серии тестов с чистого листа
- Расширенное логирование с маркерами:
  * [MODE] EXPLICIT/AUTO — какой режим выбран пользователем
  * [PROBE] UDP/TCP/VK/DPI/latency/whiteList — результаты зондирования сети
  * [EVIDENCE] проверка протокола — handshake + traffic + health
  * [FAILOVER] причина переключения протокола
  * [ROAM] смена сети в explicit-режиме
  * [DEATH] смерть туннеля (session age, alive workers, причина)
- Health monitor для WDTT (проверка дельты rx каждые 10с, failover через 75с idle)

Разделение режимов (манифест Р-22):
- EXPLICIT: только выбранный протокол, без failover на другие
- AUTO: Smart Connect ищет оптимальный протокол, failover на следующий кандидат

Версия 0.8.0+86.
