Hydra Client 0.7.3 — защита от Doze + фикс AUTO-режима

1. WakeLock (PARTIAL_WAKE_LOCK):
   - CPU не засыпает при выключении экрана
   - WDTT-сессии не закрываются по idle-timeout TURN
   - acquire при старте туннеля, release в stop()

2. SCREEN_ON receiver:
   - Мгновенная проверка здоровья туннеля при пробуждении
   - Если процессы мертвы → triggerReconnect("screen-on-wake")

3. Battery optimization exemption:
   - ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS при первом запуске
   - Разрешение WAKE_LOCK в AndroidManifest

4. AUTO-режим сбрасывает explicitProtocol:
   - Конец ложной блокировке failover после explicit-тапа
   - В логе: MainActivity.explicitProtocol = null перед autoConnect()

Версия 0.7.3+73.
