Hydra Client 0.3.3 — hotfix бесконечной установки

Исправлено:
- Добавлен permission REQUEST_INSTALL_PACKAGES (Android 8+) для установки APK
- setLastCheckedUpdate вызывается ПЕРЕД показом диалога (race condition fix)
- Защита от повторного показа диалога если приложение умерло во время выбора

Новое (из 0.3.1):
- QR-импорт ключей (панель генерирует, клиент сканирует камера/галерея)
- Intent-фильтры для импорта из файлового менеджера / шаринга / диплинков

Установка:
1. Скачай hydra-client-0.3.3-arm64.apk (реальные устройства) или -x86_64 (эмулятор).
2. Установи поверх v0.3.0/v0.3.1 (подпись совместима).
3. При предложении обновления выбери «Обновить» — установка пройдёт один раз.
