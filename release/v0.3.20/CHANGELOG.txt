Hydra Client 0.3.20 — честный статус AWG (handshake по факту трафика)

- Убрана преждевременная установка isHandshakeComplete=true при старте
  Go-туннеля: UI больше не показывает "connected", пока рукопожатие не
  состоялось фактически.
- AWG traffic-watcher: handshake считается состоявшимся, когда через tun0
  пошли дешифрованные пакеты (rx_bytes > 0 в sysfs).
- Stall-детект: 45 сек без движения счётчиков при установленном флаге ->
  статус возвращается в connecting (видим деградацию вместо вечного "connected").
- Watcher гасится в stop().
