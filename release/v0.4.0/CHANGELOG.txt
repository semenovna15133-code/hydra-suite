Hydra Client 0.4.0 — UI «Neon Hydra»: визуальный редизайн

Новый главный экран:
- Фон: глубокий космос с виньеткой
- Центр: большая круглая кнопка АВТО (~200dp) с многослойным неоновым кольцом
  * idle — тёмное кольцо с «дыханием» (pulse 1.0→1.03)
  * подключение — вращающийся conic-gradient свип + рябь
  * подключено — ровное свечение cyan→green
  * ошибка — янтарно-красный пульс
- Вокруг кнопки три «головы»-протокола под 120°:
  * AWG (cyan #00E5FF)
  * WDTT (blue #2979FF)
  * AIVPN (violet #D500F9)
  Тап по голове = форсировать протокол
  Тап по центру = авто/подключить/отключить
- Низ: живая карточка статистики
  * Спидометр rx/tx с иконками
  * Время сессии
  * Воркеры WDTT (если активны)
  * Протокол в чипе сверху карточки

Палитра: bg #05060E, cyan #00E5FF, blue #2979FF, violet #D500F9,
success #00FFC4, warn #FFB300, error #FF5252. Неоновые тени через
BoxShadow в 2-3 слоя.

Вся логика (poll/connect/failover/watchdog) не тронута — только UI.
