
## Установка для тестеров (sideload)

1. Открой релиз: https://github.com/semenovna15133-code/hydra-suite/releases/latest
2. Один раз отключи Play Protect: Play Маркет → аватар → Play Защита → шестерёнка → выключи сканирование
3. Скачай `hydra-client-*-arm64.apk` и установи
4. Импортируй Key File v2, нажми «Подключить»

Подробности и скриншоты — в notes релиза.
